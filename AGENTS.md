# Repository Notes — Agent Instructions

## Standing preferences
- **Always include relevant images/diagrams where necessary.** When producing notes,
  documents, slide decks or PDFs for this repository, add appropriate visuals
  (diagrams, waveforms, block diagrams, tables-as-figures) at the points where they
  improve understanding — do not deliver text-only documents. This applies every time.
- Prefer **accurate, programmatically drawn diagrams** (matplotlib / PIL) for technical
  content such as waveforms, timing diagrams and block diagrams, so labels and values
  are correct. Use generated/illustrative images only for non-technical decoration.
